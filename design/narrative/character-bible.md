# Character Bible — ทีมก้อนนุ่ม x Design Studio

อัปเดตล่าสุด: 2026-10-17 (สำเนาจาก Project "Playground" → claude/character-bible.md)
คอนเซปต์: ตัวละครก้อนนุ่ม 6 ตัว แต่ละตัวมีความสามารถ นิสัย ของประจำตัว สกิล/อาวุธต่างกัน และผูกกับ service ของ Design Studio
สถานะของประจำตัว/สกิล/อาวุธ: ใช้เป็นเวอร์ชันตั้งต้น แก้ไขได้ภายหลัง

## ตัวที่ 1 — ใหม่ (ทรงแฉก สีชมพู)
- บทบาท: CI / Branding Experience
- MBTI: INFJ
- นิสัย: มีความคิดสร้างสรรค์ พร้อมช่วยเหลือ สนใจอะไรใหม่ๆ ไม่ค่อยมั่นใจ เสียงเบา
- จุดอ่อน/ทริกเกอร์: รู้สึกแย่ถ้าตัวเองเป็นตัวถ่วง
- ของประจำตัว: พู่กันอัตลักษณ์ (Identity Brush)
- อาวุธ: ตราประทับโลโก้ — ปาแล้วสิ่งที่โดนกลายเป็นสีแบรนด์เดียวกัน
- สกิล: Brand Aura — บัฟให้งานทั้งทีมมีเอกลักษณ์ชัดขึ้น
- กลไกนิสัย: ได้รับคำชม/ขอบคุณ → มั่นใจขึ้น ปลดล็อกสกิลขั้นสูง / รู้สึกเป็นตัวถ่วง → พลังลด

## ตัวที่ 2 — (ทรงสี่เหลี่ยม สีชมพู)
- ยังไม่กำหนด (ตัวเลือกบทบาทที่คุยกัน: Project Manager, Content/Copywriting, QA)

## ตัวที่ 3 — มิน (ทรงหยด สีม่วง)
- บทบาท: บริหารดูแลรอบด้าน (CEO)
- MBTI: ENFJ
- นิสัย: มั่นใจ พร้อมลุย ยอมรับและเปิดกว้าง ใจแลกใจ
- จุดอ่อน/ทริกเกอร์: นอยง่าย คิดเล็กคิดน้อยถ้ามีอะไรมากระทบ
- ของประจำตัว: เข็มทิศทิศทางบริษัท
- อาวุธ: ธงนำทัพ
- สกิล: Rally — บัฟทั้งทีม / Allocate — แจกงานให้ตรงความถนัด
- กลไกนิสัย: ทีมเปิดใจคุยกัน → พลังเพิ่ม / โดนวิจารณ์แรง → สถานะ "คิดมาก" ต้องมีคนปลอบก่อนลุยต่อ

## ตัวที่ 4 — แอ๊ค (ทรงปริซึม สีเขียว)
- บทบาท: User Interface / Motion style
- MBTI: ISFJ (ยังไม่แน่ใจ)
- นิสัย: ละเอียดอ่อน เนี้ยบ ชอบความสวยงาม ให้ความสำคัญกับ Visual Feeling
- จุดอ่อน/ทริกเกอร์: นอยถ้ารู้สึกว่าคนอื่นไม่ให้ความสำคัญ
- ของประจำตัว: ปริซึมหักเหแสง
- อาวุธ: ไม้บาตองคีย์เฟรม — ชี้แล้วสิ่งของขยับลื่นตาม easing
- สกิล: Pixel Perfect — จับจุดผิดเพี้ยนเล็กๆ / Smooth Flow — ทำให้การเคลื่อนไหวนุ่มนวล
- กลไกนิสัย: งานถูกข้าม/ไม่มีใครเห็นคุณค่า → แสงปริซึมหม่น พลังลด

## ตัวที่ 5 — ฟ้า (ทรงเมฆ สีฟ้า)
- บทบาท: Handoff / Dev Frontend, ใช้ AI Technology เก่ง
- MBTI: INFJ
- นิสัย: มีความเป็นส่วนตัวสูง ทำงานเร็ว ละเอียดกับจุดเล็กๆ
- จุดอ่อน/ทริกเกอร์: แอบวีนง่ายถ้าขัดใจ
- ของประจำตัว: เมฆเก็บโค้ด
- อาวุธ: สายฟ้า AI — ผ่าลงไปแล้วงานซ้ำๆ เสร็จอัตโนมัติ
- สกิล: Cloud Deploy — ส่งงานไวที่สุดในทีม / Spec Rain — โปรยสเปกละเอียดทุกจุด
- กลไกนิสัย: ต้องมีพื้นที่ส่วนตัว / ถูกสั่งแก้กะทันหัน → โหมดฟ้าคะนอง โจมตีแรงขึ้นแต่ทีมขวัญเสีย

## ตัวที่ 6 — ไผ่ (ทรงดอกไม้ สีม่วงอ่อน)
- บทบาท: UX / CX ถนัดคิด Idea มองประสบการณ์ผู้ใช้เป็นหลัก
- MBTI: ENFP
- นิสัย: เบื่อง่าย ไม่อยู่นิ่ง พลังงานล้น เสียงดัง ชอบคุยกับคนอื่น มองภาพกว้างแต่ไม่ค่อยละเอียด
- จุดอ่อน/ทริกเกอร์: ซึมถ้าไม่มีใครสนใจ
- ของประจำตัว: แว่นส่องใจผู้ใช้
- อาวุธ: ไมค์เสียงดัง — ปล่อยคลื่นไอเดีย
- สกิล: Idea Bloom — แตกไอเดียหลายทางพร้อมกัน / Empathy Map — อ่านความต้องการลูกค้า
- กลไกนิสัย: อยู่นิ่งนาน → เบื่อ / ไม่มีใครคุยด้วย → ดอกเหี่ยว พลังหาย / จับคู่กับแอ๊คหรือฟ้า → ได้ความละเอียดเพิ่ม

## Pipeline งาน (ใช้เป็นโครงเควสต์ในเกมต่อสู้ — พักไว้)
ไผ่ (UX) → ใหม่ (Branding) → แอ๊ค (UI/Motion) → ฟ้า (Handoff/Dev) โดยมี มิน คุมทั้งกระบวนการ
