## 2. Core loop
เปิดเกม → เห็นสัตว์เลี้ยงบอกความต้องการผ่านสีหน้าและไอคอน → พาไปห้องที่ใช่แล้วดูแลด้วยการสัมผัส → ตัวละครมีความสุข พูดและตอบสนองตามนิสัย → ปิดเกม ความต้องการค่อยๆ ลดลงตามเวลาจริง → กลับมาดูแลใหม่

## 3. ความต้องการ (Needs) — ร่างแรก ให้ Loop ปรับตัวเลข
| Need | ลดลงเพราะ | เติมด้วย | สัญญาณบอก |
|---|---|---|---|
| อิ่ม | เวลา | ลากอาหารเข้าปาก | ท้องร้อง มองตู้เย็น ไอคอนจาน |
| ปวดห้องน้ำ | เพิ่มหลังกินและตามเวลา | ลากตัวละครไปห้องน้ำ | ตัวสั่น ขยับขาไปมา ไอคอนชักโครก |
| สนุก | เวลา, เบื่อ | ลูบ ดึง บีบ มินิเกม | หาว มองไปทางอื่น |
| ใกล้ชิด (เหงา) | ไม่มีใครแตะ | ลูบหัว คุยด้วย พูดตาม | ซึม พูดว่าเหงา |

- ลดลงตามเวลาจริงแม้ปิดเกม แต่ **ไม่ตาย ไม่ป่วย** แค่อารมณ์ไม่ดี (เล่นได้ทุกวัย)
- นิสัยตัวละครเปลี่ยนความเร็ว เช่น ไผ่เหงาเร็ว ฟ้าเหงาช้า (ค่าเดิมจาก Squish Pet)
- (ภายหลัง) พลังงาน/นอน + ธีมกลางวันกลางคืน

## 4. ห้องใน MVP
ปัดซ้ายขวาเพื่อเปลี่ยนห้อง
1. **ห้องนั่งเล่น**: เล่น ลูบ ดึง บีบ พูดตาม
2. **ห้องครัว**: ถาดอาหาร ลากอาหารเข้าปาก ปากจะอ้ารอเมื่ออาหารเข้าใกล้
3. **ห้องน้ำ**: ลากหรือกดค้างที่ตัวละครเพื่ออุ้มมานั่งชักโครก แล้วกดชักโครก

## 5. HUD (ไม่มีแถบข้าง)
- บน: ไอคอนความต้องการ 4 อันทรง blob เติมระดับด้วยสี (จางเมื่อพร่อง ใช้ชมพูหม่นตามแบรนด์ ไม่ใช้แดงสด)
- บนขวา: เหรียญ (ใช้ตอนมีมินิเกม) · ตั้งค่า
- ล่าง: ปุ่มตามห้อง (ครัว = ตู้เย็น, ห้องน้ำ = ชักโครก) + จุดบอกห้อง
- ไมค์: ปุ่มกลมสำหรับพูดให้ตัวละครพูดตาม
- เลือกตัวละคร: หน้าเปิดเกม และเปลี่ยนได้จากตั้งค่า

## 6. Asset: ทีมทำเองได้ / คุณต้องเตรียม
**ทีมทำเองได้ (สร้างด้วยโค้ด คุมโทนเดียวกันอัตโนมัติ)**
- ตัวละคร 3D ทั้ง 6 ตัว + สีหน้า (มีแล้ว) และท่าทางใหม่ (กิน เคี้ยว นั่งชักโครก ตัวสั่น)
- ห้อง เฟอร์นิเจอร์ อาหาร ชักโครก แบบดินปั้นด้าน
- HUD และเมนูตาม Design System (ใน Figma และในเกม)
- เสียงเอฟเฟกต์สังเคราะห์ + ระบบพูดตามเสียงผู้เล่น
- เพลงชั่วคราวระหว่างพัฒนา

**คุณต้องเตรียมหรือตัดสินใจ**
1. สิทธิ์เข้าถึงไฟล์ Figma Design System / Brand Guideline (ไอคอน SVG, โลโก้, token)
2. ค่าสีโหมดสว่างที่ยัง [TBD] ใน design.md และหัวข้อ Voice & Tone
3. ชื่อและนิสัยตัวที่ 2 (สี่เหลี่ยมชมพู)
4. คนพากย์เสียงแต่ละตัว + ไฟล์เสียงตามสคริปต์ที่ Echo เตรียม
5. เพลงประกอบที่มีสิทธิ์ใช้ (lo-fi ~100 BPM ตาม design.md)
6. GitHub repo สำหรับเก็บโค้ดและเปิดลิงก์บนมือถือ (GitHub Pages)
7. มือถือทดสอบ iPhone 1 เครื่อง + Android 1 เครื่อง
8. ชื่อเกมและไอคอนแอป
9. (ถ้าต้องการของละเอียดกว่าที่โค้ดทำได้) โมเดล 3D .glb จากนักทำ 3D หรือ AI ตาม style sheet ที่ Prop เขียน
